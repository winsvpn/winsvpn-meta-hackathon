1. WHAT WAS PROVED
   - validator.go: now rejects any Action whose Kind is not in validKinds (closed set: connect, rotate_key, report) via IsValidKind, returning ErrUnknownKind.
   - validator.go: now rejects any Action carrying a Param with empty Name (p.Name == ""), returning ErrMalformed: param name empty, regardless of kind or contract.
     This guards kinds with empty Allowed sets (ActionReport, ActionRotateKey) that previously accepted a nameless param as valid (probe showed report+empty => <nil> before fix, now => ErrMalformed).
