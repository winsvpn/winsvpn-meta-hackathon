1. WHAT WAS PROVED
   The per-kind validator in winn3/agent/validator.go rejects a legal-kind action with a missing required param.
   Specifically, a connect action with no endpoint param is rejected with ErrMalformed and a Reason naming the missing param.

   Terminology: the production contract names the connect endpoint as host (and gateway_id). The test contract uses host as the single required param. Both refer to the dial endpoint (spain-madrid:443 in fixtures). A custom contract requiring endpoint demonstrates the same path with the literal name endpoint. In all cases the validator returns ErrMalformed with message kind "connect" missing required param "<name>".

2. CONTRACT UNDER TEST
   productionContracts in validator.go:
     ActionConnect: Required: [gateway_id, host]  Allowed: [gateway_id, host]
     ActionRotateKey: Required: [key_id, algorithm] Allowed: [key_id, algorithm]
     ActionReport: {}  (no required params)
   testSchema in validator_test.go (the three controls):
     ActionConnect: Required: [host] Allowed: [host]
     ActionRotateKey: {}
     ActionReport: {}
   Both enforce: connect without its endpoint param must be ErrMalformed, not nil and not ErrUnknownKind.

3. FIXTURE AND CODE PATH

   validator.go ActionSchema.Validate checks:
     - nil action => ErrMalformed
     - empty param Name => ErrMalformed: param name empty
     - unknown kind via IsValidKind => ErrUnknownKind
     - for each Required name, if not in have map => ErrMalformed: kind "connect" missing required param "<name>"
     - if Allowed non-empty, any unexpected param name => ErrMalformed
