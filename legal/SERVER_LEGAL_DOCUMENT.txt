Privacy and Verified No Log policy. Before the user accepts the bundled Privacy Policy, the app uses only protected local settings needed to remember that choice and does not read a device hardware identifier, retrieve coarse public-IP location, fetch nodes or other network data, run tunnel or speed-test smoke checks, or request battery-optimization changes. After acceptance, the app sends a random app-install identifier generated on the device as a Device or other ID with device model, platform, app version, locale, account or free-access identity, selected location, and capability flags. That identifier is created locally and is not derived from a device hardware identifier or an advertising identifier; on Android, Windows, and Linux it is kept in the app's private storage and reinstalling produces a new one, and on Apple platforms it is kept in the device keychain and can survive a reinstall on the same device. The identifier may be account-linked for account management, the three-device limit, security, fraud prevention, and abuse prevention; it is not used for ads or tracking, sold, or shared for advertising. The app also generates a long-lived cryptographic key pair on first use of each account and sends the derived public key to Win's VPN with every account verification and configuration renewal request as a persistent identifier for connection provisioning, the three-device limit, and abuse prevention; the private key never leaves the device, and the account-side record is deleted or overwritten when the device is deactivated, replaced, or no longer needed. Win's VPN does not collect or keep VPN activity logs and does not log browsing history, DNS query history, traffic contents, raw VPN traffic, or user destination activity. Free-access verification and sign-out create a 30-day event containing the shared free identity, device and source-IP buckets, device public-key fingerprint, platform and device model, selected gateway, stealth choice, a user-agent hash, and time. It records that a free connection happened and which gateway served it, never what was done through it; paid accounts do not generate those events. "Verified No Log" is Win's VPN's name for these commitments and has not been independently audited or attested as of this version. Selected split-tunneling package identifiers stay in protected local settings and are passed locally to the operating-system VPN service; the full installed-app inventory is not uploaded. So that the app can still reach a working gateway when the usual DNS or CDN paths are censored, it also requests a small gateway-recovery file hosted on GitHub at raw.githubusercontent.com; GitHub receives the connection IP and ordinary request metadata, while no account or device identifier is sent. Only after the user requests the approximate-location map, the disconnected app asks first-party Win's VPN origins and gateways for an IP-derived scene, then uses Cloudflare's speed.cloudflare.com/meta as the final fallback. These services receive the pre-VPN connection IP and ordinary request metadata. Apple Maps receives the requested region and connection IP on Apple platforms; on other platforms a first-party Win's VPN endpoint serves OpenStreetMap-derived tiles. The app does not request device GPS or retain returned IP, city, postal-code, or map-view history. While disconnected, the app may query api.ipify.org to display the current public IP address; no account or device data is sent, and the request is never made while a VPN tunnel is active. When the user runs the speed test, the named test operators receive the connection IP, ordinary request metadata, and measurement traffic, with no account or device data. Short-lived request counters and security-event records use hashed source-IP, device, or account values and never contain VPN traffic, browsing history, DNS queries, or destination activity. Transient connection/session state is cleared when the VPN disconnects. Camouflage safety mode. Android and iOS launcher icon camouflage and Android/iOS in-app calculator camouflage are user-safety features for high-risk censorship environments, including Burma/Myanmar, where a visible VPN interface can expose users to retaliation.
