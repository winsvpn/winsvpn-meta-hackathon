WEAR OS COMPANION

The Wear OS package contains no Winn, AmneziaWG, or Xray engine. It uses
AndroidX, Jetpack Compose, Wear Compose, Kotlin coroutines, and Google Play
services Wearable at the exact Gradle-resolved versions. Apache-2.0 notices for
the AndroidX/Kotlin components and applicable Google SDK terms must accompany
the Wear package. The release gate rejects a Wear legal manifest that claims a
VPN engine is present.

BROWSER COMPANIONS

The Chrome, Edge, and Firefox companion runtime is first-party JavaScript and
uses no registry runtime dependencies. A pinned esbuild executable transforms
JavaScript at build time but is not included in the store package. The browser
legal bundle therefore contains the Win's VPN software license and controlling
terms but does not claim that Winn, AmneziaWG, Xray, or esbuild ships inside the
extension.

PARKED OR ABSENT COMPONENTS

The Mullvad Windows split-tunnel driver and hev-socks5-tunnel/lwIP are not
shipping components. They must not appear as bundled runtime identities in a
release receipt. Reintroducing either component requires a new license and
provenance review before packaging.
