#### DB-07 root cause and exact fix

`StartTunnelPowerProtection` writes `$!` to a persistent file. `StopTunnelPowerProtection` reads that number and runs `kill` without proving that the current process is the inhibitor it started. PID reuse breaks the identity assumption.

Replace `PowerInhibitPidFile`, `StartTunnelPowerProtection`, and `StopTunnelPowerProtection` with a named transient user unit. systemd then owns process identity and cgroup cleanup:

```cpp
constexpr const char* kPowerInhibitUnit = "winsvpn-power-inhibit.service";

void StartTunnelPowerProtection() {
  RunShScript(
      "UNIT=\"$1\"\n"
      "if ! command -v systemd-run >/dev/null 2>&1 || "
      "! command -v systemctl >/dev/null 2>&1 || "
      "! command -v systemd-inhibit >/dev/null 2>&1; then\n"
      "  exit 0\n"
      "fi\n"
      "if systemctl --user is-active --quiet \"$UNIT\"; then\n"
      "  exit 0\n"
      "fi\n"
      "systemctl --user reset-failed \"$UNIT\" >/dev/null 2>&1 || true\n"
      "systemd-run --user --quiet --unit=\"$UNIT\" "
      "--property=Type=exec --property=CollectMode=inactive-or-failed -- "
      "systemd-inhibit --what=sleep:idle --why=\"Win's VPN active tunnel\" "
      "--mode=block sleep infinity >/dev/null\n",
      "winsvpn-power-inhibit", {kPowerInhibitUnit}, ProcOutput::kSuppress);
}

void StopTunnelPowerProtection() {
  RunShScript(
      "UNIT=\"$1\"\n"
      "if command -v systemctl >/dev/null 2>&1; then\n"
      "  systemctl --user stop \"$UNIT\" >/dev/null 2>&1 || true\n"
      "  systemctl --user reset-failed \"$UNIT\" >/dev/null 2>&1 || true\n"
      "fi\n",
      "winsvpn-power-inhibit", {kPowerInhibitUnit}, ProcOutput::kSuppress);
}
```

#### DB-12 root cause and exact fix

The parser treats any unrecognized text as one month and accepts any digit count. Replace it with bounded explicit syntax:

```python
class DurationParseError(ValueError):
    pass


def parse_duration(duration: str):
    raw = (duration or "").strip().lower()
    if raw in {"lifetime", "life", "10y"}:
        return relativedelta(years=10)
    match = re.fullmatch(r"([1-9][0-9]{0,3})([dmy])", raw)
    if match is None:
        raise DurationParseError("duration must be 1d to 3650d, 1m to 120m, or 1y to 10y")
    amount = int(match.group(1))
    unit = match.group(2)
    limits = {"d": 3650, "m": 120, "y": 10}
    if amount > limits[unit]:
        raise DurationParseError("duration exceeds the 10-year maximum")
    if unit == "d":
        return relativedelta(days=amount)
    if unit == "m":
        return relativedelta(months=amount)
    return relativedelta(years=amount)
```

### 4.10 Performance and memory assessment

Verified controls:

- QUIC client receive windows are bounded at 128 KiB initial and 512 KiB maximum per stream, 256 KiB initial and 2 MiB maximum per connection in `winn_protocol_experimental/internal/carrier/h3.go:1112-1122`.
- Linux subprocess output is capped, pipes are close-on-exec, and waits handle interruption.
- Android removed the full-session Wi-Fi performance lock. It uses short scoped locks and fails connection setup if teardown cannot finish in 2.5 seconds.
- PMTU discovery is enabled in the QUIC configuration. Signed plans constrain MTU values rather than accepting arbitrary network input.
- Server socket buffer maximums are ceilings, not eager allocations. Raising them does not itself consume the maximum per socket.

Remaining performance risks:

- iOS memory is the main blocker. A 2 MiB QUIC connection window is reasonable in desktop and server contexts but consumes a meaningful part of a strict 15 MiB extension budget when added to three Go runtimes, Swift, packet queues, crypto state, and Network Extension overhead.

- The Linux power inhibitor should be tied to a transient unit or a D-Bus inhibitor FD, not a PID file.
- Speed Brain currently spends bytes and console noise on an optimization the CSP rejects.
- Do not enlarge socket buffers or MTU merely to improve benchmark throughput. First record throughput, CPU per Gbit, wakeups, RSS or physical footprint, reconnect latency, packet loss, and battery drain on each target architecture.
