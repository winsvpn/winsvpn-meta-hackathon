   os_proc_available_memory() does not exist, so the stock gate refuses every
   winn start with appex_available_memory_unknown (code 1018). Lane change:

   traffic path reused from the Windows/Linux machinery). Without the ACK,
   macOS keeps its contained default, byte-identical to HEAD.
