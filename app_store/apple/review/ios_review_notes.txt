Win's VPN iOS App Review Notes

OWNER APPROVED 2026-08-31; COUNSEL REVIEW PENDING. This marking does not state
or imply that counsel reviewed these notes.

Bundle ID:
org.winsvpn.app

Purpose:
Win's VPN is a VPN client that uses Apple's Network Extension Packet Tunnel
framework to provide secure VPN connectivity. The PacketTunnel extension bundle
ID is org.winsvpn.app.PacketTunnel. Winn v3 is the primary tunnel protocol; if
Winn v3 cannot connect, the app uses the Winn v1 compatibility path with AWG
(AmneziaWG) first, then Xray.

Device label:
The iOS app and the embedded watchOS companion use the device-visible name
Win's VPN. The App Store product icon uses the red panda Guardian artwork.
iOS continues to display its normal VPN status while a tunnel is active.

Embedded non-VPN watchOS companion:
The iOS IPA embeds a watchOS companion (bundle ID
org.winsvpn.app.watchkitapp, executable WinsWatch, device label Win's VPN).
The companion is a non-VPN remote for the iPhone. It does not run Network
Extension, does not start a tunnel, and cannot approve the iOS VPN permission
prompt. Connect and disconnect commands are sent to the iPhone, where
PacketTunnel starts or stops the VPN. The watch companion collects no App
Privacy data. This IPA is not an Apple TV app.

How to test:
1. Install and launch the iOS build.
2. Accept the app's legal/privacy prompts if they appear.
3. Set a six-digit PIN and use Try Free Server when no paid account number is
   available. Fresh enrollment requires a six-digit PIN and refuses repeated
   digits, counting sequences, and repeating patterns. Use the six-digit PIN
   the reviewer set. Do not use a trivial all-zero or counting PIN.
4. If the calculator safety screen is visible, enter that six-digit PIN using
   the calculator number buttons to reveal the VPN interface. Leading-zero
   PINs that are not trivially guessable are accepted.
5. Tap the normal connect action.
6. Approve the iOS VPN configuration prompt if it appears. The watch companion
   cannot complete this step.
7. Wait for the app to show connected/readiness status.
8. Use the disconnect action and confirm the status returns to disconnected.

Calculator camouflage disclosure:
The iOS app includes a calculator safety screen for users in high-censorship
environments where a visible VPN interface can create personal risk. It is a
functional calculator, and entering the user's configured six-digit PIN
reveals the VPN interface. This behavior is fully disclosed here for App Review.
While that safety screen is active, the app uses the disclosed CalculatorIcon
alternate home-screen icon through UIApplication.setAlternateIconName. iOS may
show its standard icon-change confirmation. Entering the configured PIN restores
the primary red panda Guardian home-screen icon. The App Store product icon
uses the red panda Guardian artwork, and iOS continues to display its normal
VPN status while a tunnel is active.
The PIN verifier is a salted PBKDF2 hash stored only in the app's local storage;
the PIN and entered digits are not transmitted.

Payment/purchase note:
The Apple build's Premium Access Info button opens the developer's home page,
https://www.winsvpn.org, in the user's browser. The app embeds no payment SDK,
offers no in-app purchase, and does not open a checkout or payment page. Users
can use an existing Win's VPN account number or Try Free Server.
The mandatory pre-use clickwrap does describe the external PayPal recurring
plan terms and displays the billing URL as plain text. It contains no tappable
purchase control, and the app opens no purchase page.

Privacy note:
The app is designed not to collect browsing history, DNS query contents,
traffic contents, destination activity logs, contacts, photos, health data, or
precise location. Only after the user asks to show the approximate-location
map, the disconnected app first asks compiled first-party Win's VPN origins and
gateways for an IP-derived scene, then uses Cloudflare's coarse network metadata
endpoint as the final fallback. The lookup is not automatic at launch. It then
centers a standard Apple MapKit view, and Apple supplies the map tiles. The app
reads only the coarse map-center fields and does not retain returned IP, city,
or postal-code fields.
The four linked App Functionality privacy types are Coarse Location, User ID,
Device ID, and Product Interaction. They are not used for tracking. Product
Interaction covers selected VPN location, stealth mode, and Double VPN choices
sent with persistent account and device identifiers. Purchase History is not
collected. Limited account/device/setup metadata is used for device limits,
abuse prevention, legal acceptance, service access, and support.
The app does not request Apple's Location Services permission. The blue marker
is a small visual indicator for the already disclosed rounded, IP-derived
Coarse Location and does not represent precise GPS location.
